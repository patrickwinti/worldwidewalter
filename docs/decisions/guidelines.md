# Team 4 
## Guidelines 

### Meetings 
- Once a week on Wednesday according Schedule.

- Every 2 Weeks: Sprint Review
- If needed/requested by team meetings outside these times can be planned.

### Programming Tools 
- Intellij: Programming environment. 
- Maven: Build automation tool.
- Jira: Issues/task tracking. 
- Angular: Frontend Development

### Communication
* Jira: All questions about tickets are asked in the specific ticket with the @-mention.
* Teams: Generic questions in Teams chat with the @-mention

### Coding 
* Each feature has at least one own branch
* Code on the Main branch runs without issues, no unfinished code in the main branch
* No branch will get merged that does not meet the requirements:
  * Clean coding guidelines
  * Test coverage
  * Javadoc coverage
      * All public methods (except getters and setters) have documentation
- Feature branches: for **all public methods** have been tested (Unit Tests) and are properly doccumented.
- Try breaking features into smaller tasks and create, if possible, smaller PRs
