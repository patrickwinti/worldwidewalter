# Guidelines

#### Tools

* IntelliJ
* Java
* Maven
* Angular

#### Communication

* Jira: All questions about tickets are asked in the specific ticket with the @-mention.
* Teams: Generic questions in Teams chat with the @-mention

#### Taskmanagement
* All tasks will be represented by a ticket on JIRA. This holds true for developing as well as non-development tasks, like documentation or project setup.

#### Coding
* Each feature has at least one own branch
* No branch will get merged that does not meet the requirements:
  * Clean coding guidelines 
  * Test coverage
  * Javadoc coverage
    * All public methods (but getters and setters) have documentation
* Everything on _main_ works as specified
* Try breaking features into smaller tasks and create, if possible, smaller PRs

#### UML
* Class diagram will be updated in the development phase.

#### Reviewing
 All PR reviews will require two reviewers. For coding PRs:
1. First review by a less experienced coder
2. Second review by a more experience coder

Experienced reviewers: Patrick & Carla
